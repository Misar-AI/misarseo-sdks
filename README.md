# misarseo-sdks

Mirror of the MisarSEO SDK packages, synced automatically from
`git.misar.io/misaradmin/MisarSEO` by the **Sync SDKs → GitHub** workflow
(`.forgejo/workflows/sync-sdks-to-github.yml`).

- `ts/` — `@misar/seo` (TypeScript SDK)
- `mcp/` — `@misar/seo-mcp` (MCP server)

Do not edit this repository directly — changes are overwritten on every sync.
